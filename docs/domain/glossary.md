# Glossario

| Termine | Significato |
| --- | --- |
| Player | Calciatore reale, identità condivisa nel catalogo. |
| Club | Squadra reale del calciatore. |
| League | Lega di fantacalcio, persistente negli anni. |
| LeagueSeason | Edizione della lega in una stagione, con regole e budget. |
| Team | Squadra fantacalcio in una LeagueSeason. |
| TeamMember | Collegamento tra utente e squadra con cui partecipa. Indipendente dal permesso di organizzatore. |
| LeagueMember | Utente membro di una lega e relativi permessi. |
| ListVersion | Versione importata del listone, adottata esplicitamente dalla lega. |
| AuctionSession | Sessione con giro di chiamata e più giocatori in sequenza. |
| PlayerAuction | Asta del singolo giocatore, con timer e configurazione propri. |
| Bid | Offerta totale accettata dal server. |
| CommandReceipt | Esito persistito di una richiesta identificata univocamente. |
| Chiamante | Partecipante di turno: avvia l’asta e offre automaticamente 1 credito. |
| Organizzatore | Membro con permessi di gestione della lega/sessione. |
| SuperAdmin | Ruolo globale Identity; unico abilitato a creare leghe nella prima versione. |
